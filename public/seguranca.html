Segurança e Privacidade

A proteção dos seus dados e dos dados dos seus clientes é prioridade máxima no LinkMágico.

🔒 Infraestrutura

✓ HTTPS Obrigatório

Todas as conexões são criptografadas com TLS 1.2+. Nenhum dado trafega em texto plano. O certificado SSL é renovado automaticamente.

✓ HSTS (HTTP Strict Transport Security)

O header HSTS garante que navegadores só acessem o site via HTTPS, prevenindo ataques de downgrade de protocolo.

✓ Headers de Segurança

Helmet.js aplicado com Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy e Permissions-Policy.

✓ Compressão e Performance

Gzip/Brotli em todas as respostas. Cache de 7 dias para assets estáticos com ETag e Last-Modified.

🏗️ Arquitetura

✓ Multi-Tenancy Isolado

Cada cliente (tenant) tem seu ambiente completamente isolado. Dados, configurações, chatbots e leads são separados por tenant. Um cliente nunca acessa dados de outro.

✓ API Keys Únicas

Cada tenant possui sua API Key exclusiva. Toda requisição é autenticada e autorizada no nível do tenant.

✓ Backups Automáticos

Backups automáticos de leads, conversas e configurações. Restauração disponível a qualquer momento pelo painel administrativo.

📋 LGPD (Lei Geral de Proteção de Dados)

✓ Conformidade LGPD

O LinkMágico está em conformidade com a Lei nº 13.709/2018 (LGPD). As práticas incluem:

  • Base legal: Consentimento do titular e legítimo interesse para processamento de dados.
  • Minimização: Coletamos apenas os dados necessários (nome, email, telefone) para a prestação do serviço.
  • Transparência: Política de Privacidade e Termos de Uso acessíveis publicamente.
  • Direitos do titular: Acesso, correção, exclusão e portabilidade dos dados mediante solicitação.
  • Segurança: Criptografia em trânsito e em repouso, controle de acesso baseado em roles.
  • Retenção: Dados são mantidos apenas pelo tempo necessário. Exclusão disponível pelo painel.

🔐 Dados dos Leads

✓ Propriedade dos Dados

Os leads capturados pelo vendedor automático pertencem ao cliente (tenant). O LinkMágico não utiliza, vende ou compartilha dados de leads com terceiros.

✓ Exclusão de Dados

O cliente pode excluir leads individualmente ou realizar limpeza em lote a qualquer momento pelo painel administrativo.
