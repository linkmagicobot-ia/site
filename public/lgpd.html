LGPD — Conformidade com a Lei Geral de Proteção de Dados

Última atualização: 26 de junho de 2026

O LinkMágico está comprometido com a conformidade à Lei nº 13.709/2018 (Lei Geral de Proteção de Dados Pessoais — LGPD). Este documento explica como aplicamos os princípios da LGPD em nossa plataforma.

1. Papéis no tratamento de dados

PapelQuem éO que faz
ControladorO cliente (tenant) do LinkMágicoDecide por que e como os dados dos seus leads são coletados
OperadorLinkMágicoProcessa os dados dos leads em nome do cliente, conforme instruções
ControladorLinkMágicoControla os dados da própria conta do cliente (cadastro, billing)

📋 Importante: Quando o vendedor automático captura dados de um visitante (nome, email, telefone), o controlador desses dados é o cliente (tenant) que instalou o widget. O LinkMágico atua como operador, processando esses dados conforme as instruções do cliente.

2. Bases legais utilizadas

TratamentoBase legal (Art. 7º LGPD)
Cadastro e conta do clienteExecução de contrato (Art. 7º, V)
Processamento de pagamentoExecução de contrato (Art. 7º, V)
Captura de leads pelo chatbotConsentimento do visitante (Art. 7º, I) e/ou legítimo interesse (Art. 7º, IX)
Envio de comunicações sobre o serviçoExecução de contrato (Art. 7º, V)
Processamento de conversas pela IAExecução de contrato (Art. 7º, V)
Logs de acessoCumprimento de obrigação legal — Marco Civil da Internet (Art. 7º, II)
Dados de billingCumprimento de obrigação legal — legislação fiscal (Art. 7º, II)

3. Princípios aplicados

  • Finalidade: Dados são coletados para finalidades legítimas, específicas e informadas ao titular.
  • Adequação: O tratamento é compatível com as finalidades informadas.
  • Necessidade: Coletamos apenas os dados estritamente necessários (nome, email, telefone).
  • Livre acesso: Os titulares podem consultar seus dados a qualquer momento.
  • Qualidade dos dados: Garantimos exatidão e atualização dos dados.
  • Transparência: Informações claras sobre o tratamento estão disponíveis publicamente.
  • Segurança: Medidas técnicas e administrativas para proteger os dados.
  • Prevenção: Adoção de medidas para prevenir danos aos titulares.
  • Não discriminação: Dados não são usados para fins discriminatórios.
  • Responsabilização: Demonstramos conformidade com a LGPD.

4. Direitos dos titulares (Art. 18)

Todo titular de dados pessoais tem direito a:

  • ✅ Confirmação da existência de tratamento
  • ✅ Acesso aos dados pessoais tratados
  • ✅ Correção de dados incompletos, inexatos ou desatualizados
  • ✅ Anonimização, bloqueio ou eliminação de dados desnecessários ou excessivos
  • ✅ Portabilidade dos dados a outro fornecedor
  • ✅ Eliminação dos dados tratados com consentimento
  • ✅ Informação sobre compartilhamento de dados com terceiros
  • ✅ Informação sobre a possibilidade de não consentir e suas consequências
  • ✅ Revogação do consentimento

5. Medidas de segurança

  • Criptografia em trânsito: HTTPS/TLS 1.2+ em todas as conexões
  • HSTS: Strict Transport Security com preload
  • Multi-tenancy: Isolamento completo de dados entre clientes
  • API Keys únicas: Autenticação isolada por tenant
  • Helmet.js: Content-Security-Policy, X-Frame-Options, X-Content-Type-Options
  • Backups automáticos: Com possibilidade de restauração pelo cliente
  • Acesso restrito: Apenas pessoal autorizado acessa sistemas de produção

6. Compartilhamento de dados

Compartilhamos dados apenas com os seguintes operadores, estritamente para a prestação do serviço:

  • Stripe: Processamento de pagamentos
  • OpenAI / Groq: Processamento de linguagem natural (conversas do chatbot)
  • Twilio: WhatsApp Business API
  • Render: Hospedagem da infraestrutura

Não compartilhamos dados com terceiros para marketing, publicidade ou qualquer finalidade comercial.

7. Transferência internacional

Alguns operadores (Stripe, OpenAI, Render) podem processar dados em servidores fora do Brasil. Nesses casos, garantimos que os operadores oferecem nível de proteção compatível com a LGPD, conforme Art. 33.

8. Incidentes de segurança

Em caso de incidente de segurança que possa acarretar risco ou dano relevante aos titulares, nos comprometemos a:

  • Comunicar a Autoridade Nacional de Proteção de Dados (ANPD) em prazo razoável
  • Comunicar os titulares afetados
  • Informar a natureza dos dados afetados e as medidas adotadas

9. Responsabilidades do cliente (tenant)

Como controlador dos dados dos seus leads, o cliente é responsável por:

  • Informar aos visitantes que um chatbot de IA está em operação
  • Obter consentimento quando necessário para a captura de dados
  • Responder a solicitações de direitos dos titulares dos seus leads
  • Definir políticas de retenção adequadas ao seu negócio
