Glossário de Automação e IA

Termos essenciais sobre chatbots, inteligência artificial, CRM, WhatsApp e vendas digitais — explicados de forma simples.

40 termos disponíveis
A

API Técnico

Application Programming Interface — Interface que permite a comunicação entre sistemas diferentes. No contexto do LinkMágico, a API permite integrar o chatbot com outras plataformas como CRM, e-commerce e sistemas internos.

Exemplo: Usar a API do LinkMágico para enviar dados de leads automaticamente para o seu ERP.
Ver também: Webhook, SDK, Integração

Atendimento Automatizado Conceito

Uso de tecnologia (chatbots, IA, fluxos) para responder perguntas e resolver solicitações sem intervenção humana. Pode funcionar 24 horas por dia, reduzindo custos operacionais em até 80%.

Exemplo: Um chatbot de clínica que agenda consultas automaticamente pelo WhatsApp.
Ver também: Chatbot, IA Conversacional

Automação de Marketing Marketing

Uso de software para automatizar tarefas repetitivas de marketing: emails, mensagens, segmentação e nutrição de leads. Com IA conversacional, a automação se torna dinâmica — o chatbot adapta a conversa ao contexto em tempo real.

Exemplo: O chatbot qualifica leads, faz follow-up e agenda reuniões automaticamente, sem ferramentas externas de automação.
Ver também: Chatbot, Lead, Funil de Vendas
C

Chatbot Conceito

Software que simula uma conversa humana por texto ou voz. Pode ser baseado em regras (fluxos predefinidos) ou em inteligência artificial (NLP/LLM). Chatbots de vendas qualificam leads, respondem objeções e direcionam para a conversão.

Exemplo: O vendedor automático do LinkMágico é um chatbot de IA que aprende sobre o produto do cliente e vende 24/7.
Ver também: IA Conversacional, NLP, Vendedor Automático

Conversão Marketing

Quando um visitante realiza a ação desejada — comprar, agendar, preencher formulário, iniciar conversa. A taxa de conversão é a porcentagem de visitantes que convertem em relação ao total.

Exemplo: Se 1.000 pessoas visitam sua página e 30 compram, sua taxa de conversão é 3%.
Ver também: Lead, Funil de Vendas, CTA

CRM Ferramenta

Customer Relationship Management — Sistema para gerenciar o relacionamento com clientes e leads. Organiza contatos, histórico de interações, pipeline de vendas e follow-ups. O LinkMágico inclui CRM integrado.

Exemplo: Visualizar todos os leads capturados pelo chatbot organizados por status (novo, qualificado, em negociação, fechado).
Ver também: Lead, Pipeline, Lead Scoring

CTA Marketing

Call to Action — Chamada para ação. Elemento visual ou textual que incentiva o usuário a realizar uma ação específica, como "Criar Conta Grátis", "Falar com Consultor" ou "Ver Planos".

Exemplo: Um botão verde "Teste Grátis por 7 Dias" no final de um artigo do blog.
Ver também: Conversão, Landing Page
E

Evolution API Técnico

API open-source para conectar WhatsApp a sistemas externos. Alternativa à API oficial do WhatsApp Business (Twilio/Meta). Permite enviar e receber mensagens, gerenciar instâncias e automatizar atendimento.

Exemplo: Conectar o LinkMágico ao WhatsApp via Evolution API para atendimento automático sem custo de API oficial.
Ver também: WhatsApp Business API, Webhook
F

Follow-up Vendas

Ação de acompanhamento após o primeiro contato com um lead. Essencial para manter o interesse e avançar na jornada de compra. Pode ser automatizado com chatbots e sequências de mensagens.

Exemplo: Enviar automaticamente uma mensagem no WhatsApp 24h depois que o lead visitou a página de preços mas não comprou.
Ver também: Lead, Lead Nurturing, Remarketing

Funil de Vendas Vendas

Modelo que representa as etapas da jornada do cliente: Topo (descoberta), Meio (consideração) e Fundo (decisão). Cada etapa requer estratégias e conteúdos diferentes.

Exemplo: Blog post (topo) → Chatbot qualifica (meio) → IA direciona para checkout (fundo).
Ver também: Lead, Conversão, Pipeline
I

IA Conversacional Conceito

Inteligência artificial capaz de manter diálogos naturais com humanos. Utiliza NLP e LLMs para entender intenção, contexto e nuances. Diferente de chatbots de regras, adapta-se dinamicamente à conversa.

Exemplo: O chatbot do LinkMágico entende objeções como "tá caro" e responde com argumentos personalizados sobre valor e ROI.
Ver também: Chatbot, NLP, LLM

Integração Técnico

Conexão entre dois ou mais sistemas para troca automática de dados. Pode ser feita via API, webhook, SDK ou plataformas como Zapier e Make.

Exemplo: Integrar o LinkMágico com o Google Calendar para que leads agendem reuniões automaticamente.
Ver também: API, Webhook, SDK
L

Landing Page Marketing

Página web projetada para uma única ação de conversão — comprar, cadastrar, agendar. Diferente de um site completo, foca em um produto/oferta específico com mínimas distrações.

Exemplo: Instalar o widget do LinkMágico na landing page de um curso online para converter visitantes em alunos.
Ver também: Conversão, CTA, Widget

Lead Vendas

Pessoa que demonstrou interesse no seu produto ou serviço — deixou contato, fez pergunta, interagiu com o chatbot. Um lead qualificado tem perfil e intenção de compra identificados.

Exemplo: Visitante que conversa com o chatbot e informa nome, email e telefone durante a interação.
Ver também: Lead Scoring, Lead Nurturing, CRM

Lead Nurturing Vendas

Processo de "nutrir" leads com informações relevantes até estarem prontos para comprar. Inclui sequências de emails, mensagens WhatsApp, conteúdo educativo e follow-ups automatizados.

Exemplo: Enviar 5 mensagens ao longo de 7 dias com dicas e cases de sucesso antes de oferecer o plano Pro.
Ver também: Follow-up, Funil de Vendas

Lead Scoring Vendas

Sistema de pontuação que classifica leads por probabilidade de compra. Baseado em comportamento (páginas visitadas, mensagens enviadas) e perfil (cargo, segmento, tamanho da empresa).

Exemplo: Lead que visitou página de preços + interagiu com chatbot + perguntou sobre integração = pontuação alta.
Ver também: Lead, CRM, Pipeline

LLM Técnico

Large Language Model — Modelo de linguagem de grande escala (ex: GPT, Llama, Gemini). Treinado em bilhões de textos para gerar e compreender linguagem natural. Base da IA conversacional moderna.

Exemplo: O LinkMágico usa LLMs para entender perguntas complexas e gerar respostas personalizadas sobre o produto do cliente.
Ver também: IA Conversacional, NLP
M

Multi-Tenancy Técnico

Arquitetura onde uma única instância do software serve múltiplos clientes (tenants), cada um com dados completamente isolados. Garante que leads de um cliente nunca se misturem com os de outro.

Exemplo: No LinkMágico, cada cliente tem sua API Key exclusiva e ambiente isolado — dados são 100% separados.
Ver também: API, SaaS
N

NLP Técnico

Natural Language Processing — Processamento de linguagem natural. Tecnologia que permite computadores entenderem, interpretarem e gerarem texto humano. Base dos chatbots inteligentes.

Exemplo: O chatbot entende que "quanto custa?" e "qual o preço?" têm a mesma intenção graças ao NLP.
Ver também: IA Conversacional, LLM
O

Onboarding Produto

Processo de integração e boas-vindas de novos clientes ou usuários, guiando-os pelos primeiros passos do produto. Chatbots podem conduzir o onboarding de forma personalizada pelo WhatsApp, reduzindo churn e reembolsos.

Exemplo: Sequência automática de boas-vindas nos primeiros 7 dias: acesso à plataforma, primeiro módulo, grupo de alunos e acompanhamento de progresso.
Ver também: Chatbot, Follow-up, Conversão
P

Pipeline Vendas

Representação visual das etapas do processo de vendas. Organiza leads por estágio: novo → qualificado → proposta → negociação → fechado. Permite acompanhar o valor total em cada fase.

Exemplo: Ver no CRM do LinkMágico que há 15 leads em negociação, representando R$22.500 em potencial de receita.
Ver também: CRM, Funil de Vendas, Lead
R

Remarketing Marketing

Estratégia de reengajar pessoas que já interagiram com seu site ou produto. No contexto do LinkMágico, o remarketing conversacional usa WhatsApp e chatbot para recuperar leads que não compraram.

Exemplo: Enviar mensagem automática para quem visitou a página de preços mas saiu sem comprar.
Ver também: Follow-up, Lead Nurturing

ROI Métrica

Return on Investment — Retorno sobre o investimento. Mede o ganho financeiro em relação ao custo. Fórmula: ROI = ((Ganho - Custo) / Custo) × 100%.

Exemplo: Se o LinkMágico Pro custa R$69/mês e gera R$2.000 extras em vendas, o ROI é de 2.799%.
Ver também: Calculadora de ROI
S

SaaS Conceito

Software as a Service — Modelo onde o software é acessado pela internet por assinatura, sem necessidade de instalação local. O LinkMágico é um SaaS de automação de vendas com IA.

Exemplo: Em vez de comprar e instalar um software, você assina o plano Pro por R$69/mês e acessa pelo navegador.
Ver também: Multi-Tenancy, API

SDK Técnico

Software Development Kit — Conjunto de ferramentas, bibliotecas e documentação para desenvolvedores integrarem um serviço em suas aplicações.

Exemplo: Usar o SDK JavaScript do LinkMágico para personalizar o comportamento do widget de chat no seu site.
Ver também: API, Widget
V

Vendedor Automático Conceito

Chatbot de IA treinado especificamente para vender. Diferente de chatbots de suporte, o vendedor automático qualifica leads, responde objeções, apresenta benefícios e direciona para o checkout — 24 horas por dia.

Exemplo: O visitante pergunta "funciona para clínicas?" e o vendedor automático explica casos de uso, mostra resultados e oferece teste grátis.
Ver também: Chatbot, IA Conversacional
W

Webhook Técnico

Notificação automática enviada de um sistema para outro quando um evento ocorre. Diferente de API (que você consulta), o webhook avisa você proativamente.

Exemplo: O LinkMágico envia um webhook para o seu sistema toda vez que um novo lead é capturado pelo chatbot.
Ver também: API, Integração

WhatsApp Business API Plataforma

API oficial da Meta para automação de WhatsApp em escala. Permite enviar mensagens em massa, usar templates aprovados, conectar chatbots e integrar com sistemas. Disponível via provedores como Twilio.

Exemplo: Conectar o LinkMágico ao WhatsApp Business API via Twilio para atender centenas de leads simultaneamente.
Ver também: Evolution API, Chatbot

Widget Ferramenta

Componente visual incorporado em um site. No contexto do LinkMágico, é o balão de chat que aparece no canto da tela e abre a conversa com o vendedor automático.

Exemplo: Colar o código de embed do widget do LinkMágico no seu site WordPress para ativar o chatbot.
Ver também: Chatbot, SDK, Landing Page
