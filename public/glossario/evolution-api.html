O que é Evolution API

Técnico

API open-source para conectar WhatsApp a sistemas externos — alternativa à API oficial do WhatsApp Business.

A Evolution API é uma solução open-source poderosa que permite conectar o WhatsApp a aplicações externas sem depender da API oficial da Meta e seus respectivos custos por conversa. Ela atua simulando o WhatsApp Web através de um servidor.

Com essa ferramenta, empresas podem criar integrações avançadas, conectar sistemas de atendimento, enviar notificações automatizadas e plugar inteligência artificial de maneira flexível.

Principais Características

  • Self-hosted: Você mesmo hospeda a solução no seu próprio servidor (VPS ou nuvem), mantendo o controle dos dados.
  • Múltiplas instâncias: É possível conectar e gerenciar vários números de WhatsApp simultaneamente na mesma estrutura.
  • Conexão via QR Code: A autenticação é feita via pareamento de QR Code, sem burocracias de aprovação de conta empresarial.
  • Webhooks: Receba notificações em tempo real sempre que uma mensagem chegar, for lida ou o status do dispositivo mudar.
  • REST API Completa: Endpoints bem documentados para o envio de mensagens de texto, imagens, vídeos, áudios e contatos.
  • Gratuito: O código é aberto, logo, não há cobrança por mensagem enviada, diferentemente da API oficial.

Como instalar a Evolution API

O método mais seguro e utilizado pela comunidade para instalação da Evolution API é através de Docker. Em um servidor Linux, o processo resumido é:

  1. Instale o Docker e o Docker Compose em sua VPS.
  2. Crie um arquivo docker-compose.yml utilizando a imagem oficial da Evolution API, configurando variáveis de ambiente como chaves de API globais e banco de dados (ex: PostgreSQL e Redis).
  3. Execute o comando docker-compose up -d no terminal para subir os contêineres.
  4. Acesse os endpoints via Postman ou Insomnia para criar sua primeira instância e capturar o QR Code para pareamento.

Vantagens e desvantagens

A Evolution API é uma alternativa fantástica, mas possui cenários ideais de uso:

Vantagens:

  • Isenção total de taxas de disparo da Meta.
  • Não há necessidade de aprovar modelos de mensagem (templates).
  • Extrema flexibilidade para integrar com qualquer software de terceiros e CRMs.

Desvantagens:

  • Requer conhecimento técnico (ou contratação de especialistas) para instalação e manutenção de infraestrutura.
  • O número conectado está sujeito aos algoritmos anti-spam do WhatsApp e pode sofrer banimentos caso haja disparos não solicitados.
  • Depende de um celular conectado à internet, pelo menos para pareamento e manutenção de sessão.

Casos de uso mais comuns

Diversos negócios modernos se apoiam nesta API para operações críticas:

  • Chatbots com Inteligência Artificial: Conectar agentes autônomos treinados para responder clientes 24h por dia.
  • Notificações Automáticas: Envio de boletos, código de rastreamento e confirmações de agendamento via sistema ERP.
  • Atendimento Centralizado: Uso de plataformas multicanal para que vários atendentes usem o mesmo número de WhatsApp.

Perguntas frequentes

A Evolution API é gratuita?

Sim, a Evolution API é um projeto de código aberto e 100% gratuito. Os únicos custos envolvidos são com a infraestrutura de hospedagem (servidor) necessária para manter a aplicação rodando ininterruptamente.

Evolution API é segura para usar em produção?

Sim, milhares de empresas utilizam a ferramenta em produção com alta disponibilidade. Contudo, por exigir infraestrutura própria, é essencial aplicar boas práticas de segurança, como uso de HTTPS, senhas fortes e gestão eficiente de recursos do servidor.

Qual a diferença entre Evolution API e WhatsApp Business API?

A WhatsApp Business API é a solução oficial da Meta, possui cobrança por conversa e exige aprovação de templates para iniciar chats. A Evolution API é gratuita, livre de taxas por mensagem e permite o envio de mensagens de forma flexível via pareamento QR Code.
