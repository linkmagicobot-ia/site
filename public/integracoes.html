Integrações

O LinkMágico se conecta com as ferramentas que você já usa. Sem complicação.

📱 Comunicação

📱 WhatsApp — Twilio Nativo

Envie e receba mensagens via WhatsApp Business API (Twilio). Notificações de leads, follow-up automático e conversas bidirecionais.

📱 WhatsApp — Evolution API Nativo

Integração com Evolution Go v0.7.1 para WhatsApp. Conexão via QR Code, envio de mensagens, webhooks de recebimento e gestão de sessões.

🛒 Plataformas de Venda

🔥 Hotmart Webhook

Receba webhooks de venda e checkout da Hotmart. Confirme compras automaticamente e atualize o status do lead no CRM.

🌐 Sites e CMS

🔧 WordPress Embed

Instale o widget flutuante no WordPress com um simples copiar/colar no header ou footer do tema. Compatível com Elementor, Divi e qualquer tema.

🎨 Wix Embed

Adicione o código do widget via Custom Code no Wix. Funciona em todas as páginas automaticamente.

🛍️ Shopify Embed

Cole o script do widget no theme.liquid da sua loja Shopify. O vendedor automático funciona em todo o catálogo.

📄 HTML / Qualquer Site Embed

Funciona em qualquer site HTML, React, Vue, Angular, Next.js ou plataforma que aceite JavaScript embed.

🔌 API REST

⚙️ API Completa API

API REST documentada para integração avançada. Endpoints para leads, conversas, chatbots, appointments, analytics e configurações. Autenticação via API Key.

🔗 Webhooks de Saída Webhook

Configure webhooks para receber notificações em tempo real quando um lead é capturado, uma venda é confirmada ou um agendamento é realizado.
