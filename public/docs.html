⚡ API REST — Referência Rápida

Autenticação via API Key no header ou body. Base URL: https://linkmagico.app.br

Leads

POST/api/capture-leadCapturar novo lead
GET/admin/leadsListar leads
GET/admin/leads/:idDetalhes do lead
DELETE/admin/leads/:idExcluir lead

Chat

POST/api/process-chat-inteligenteProcessar mensagem com IA

Agendamento

POST/api/appointmentsCriar agendamento
GET/admin/appointmentsListar agendamentos

Analytics

POST/api/track-conversionRegistrar conversão
GET/api/conversion-statsEstatísticas de conversão

Sistema

GET/healthHealth check
GET/api/system/statusStatus do sistema
POST/validate-api-keyValidar API Key

Backup

POST/admin/leads/backup/createCriar backup
GET/admin/leads/backup/listListar backups
POST/admin/leads/backup/restoreRestaurar backup

🔗 Widget — Instalação

Código de Embed

Cole este código antes do </body> do seu site:

<script> // Gere seu código em linkmagico.app.br/admin // Cada widget tem sua própria API Key </script>

O código completo é gerado automaticamente no painel administrativo após criar seu chatbot. Funciona em qualquer site: WordPress, Wix, Shopify, HTML puro, React, Vue, Angular.
