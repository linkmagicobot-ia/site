IndexNow

O IndexNow permite notificar mecanismos de busca (Bing, Yandex, Naver) sobre páginas novas ou atualizadas instantaneamente. Configure a variável de ambiente INDEXNOW_KEY para ativar.
Configuração
  • Gerar chave IndexNow: node seo/indexnow.js generate-key
  • Configurar INDEXNOW_KEY no ambiente
  • Arquivo de verificação em public/
  • Testar envio: node seo/indexnow.js submit https://site.linkmagico.app.br/
  • Enviar todas: node seo/indexnow.js all

Validação de Produção

Execute node seo/validate-production.js para verificar HTTPS, headers, robots, sitemap e páginas de produção. O relatório será salvo em reports/production-validation.md.
Verificações
  • HTTPS ativo
  • HSTS configurado (max-age=31536000)
  • Content-Security-Policy presente
  • X-Content-Type-Options: nosniff
  • Compression (gzip) ativo
  • Cache headers configurados (7d)
  • robots.txt acessível
  • sitemap.xml acessível (72 URLs)
  • Health check respondendo
