1. O Serviço

O LinkMágico é uma plataforma SaaS (Software as a Service) que permite criar vendedores automáticos com inteligência artificial para páginas web. O serviço inclui:

  • Chatbot de vendas com IA conversacional
  • CRM integrado com pipeline de vendas
  • Captura automática de leads
  • Agendamento integrado
  • Analytics e métricas de conversão
  • Widget de chat para instalação em sites
  • Integração com WhatsApp (Twilio e Evolution API)
  • API REST para integração avançada

2. Conta e Acesso

  • Você é responsável por manter a confidencialidade da sua API Key e credenciais.
  • Notifique-nos imediatamente em caso de acesso não autorizado à sua conta.

3. Planos e Pagamento
